# 纪要引用显示与导出

纪要版本工具栏下方提供「显示引用标注」开关，默认开启。关闭后收起议题、决策、行动项、待确认问题中的时间戳引用按钮；重新开启可继续查看原文、定位转录。该偏好记在本机，不写入会议或版本快照，不改变校对与总结的输入、引用校验结果或历史内容。

「导出本版纪要」提供四个明确选项：

- Markdown（含引用）
- Markdown（不含引用）
- TXT（含引用）
- TXT（不含引用）

导出选项独立于阅读开关。含引用沿用原有格式；不含引用省略系统引用链接、编号和对应的原文依据，保留标题、版本与模型信息、正文、行动项、限制说明和人工补充。无引用版本的默认文件名带「不含引用」，可在保存窗口修改。

人工编辑版的处理只产生用于显示或导出的临时文本，不改写 `editedMarkdown`：识别输入快照中的系统引用链接、旧脚注及生成的来源块；保留人工段落、普通外链、自定义脚注、代码与转义示例。只有清理后没有内容的「原文依据」标题会被移除，其中的人工补充仍保留。

「编辑并保存新版本」始终载入含引用的完整正文，与阅读开关无关。原始引用数据仍保留在版本中，随时可以导出含引用版本。

导出 API 的 `includeCitations` 参数默认是 `true`，既有 CLI 和调用方的默认输出保持兼容。

## 验证

全套 193 项测试通过（Core 75、Cloud 86、Audio 32）。新增测试覆盖默认与自定义模板、三种纪要语言、Markdown／TXT 无引用导出、人工编辑正文和独立脚注保留，以及原始版本不被修改。App 构建与签名检查通过；实际界面验证关闭引用后按钮消失，重新开启后恢复，导出菜单显示四种明确选项。
