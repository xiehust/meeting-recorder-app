# 0.2.0 · AI 校对与纪要接入

以下保留早期版本的实现与验证记录。0.5.1 起已切换至 [Bedrock Runtime Responses 与 global 推理配置](BEDROCK-RUNTIME.md)，当前接入方式以该说明为准。

## 0.2.2 补充

- 页面顺序为“转录 → 原文 → 人物 → 术语与备注 → 校对 → 纪要”。
- “保存并前往校对”等待本地写入成功后才切换页面；保存失败时停留原页并展示存储错误。
- 保存的术语和人工补充均进入校对请求，人工补充仅作上下文，不成为原话；纪要继续独立展示用户补充。
- 会议窗口和菜单栏统一提供“静音麦克风／取消静音”，明确显示本应用状态。关闭只针对麦克风轨，会议应用音轨不被此操作停止。
- 当前不自动跟随 Teams / Zoom，也不读取按钮文字。Microsoft 旧第三方控制 API 已停止服务，参见 [Elgato 官方说明](https://help.elgato.com/hc/en-us/articles/26249796361613-How-to-pair-Stream-Deck-plugin-with-Microsoft-Teams)。
- 48 项回归测试通过；新增流程测试验证了校对先收到保存的术语与备注，再进行纪要生成，原文保持不变。测试不调用云端模型。

## 0.2.1 补充

- 校对页增加“全部接受”，作用于当前所选完整版本的待确认建议；已接受、已撤销和人工保护片段不重复处理。
- 每条接受操作保留独立审核记录，仍可逐条撤销；一批操作只推进一次审核版本，已生成纪要会提示更新。
- 过期或未完成的校对版本不能批量接受，重复操作不会增加审核记录。
- “术语与备注”页明确说明：术语用于 AI 校对，不影响实时转录；人工补充用于纪要参考及独立展示，并随原文／人工修订稿导出。保存后，下次 AI 处理才会使用新内容。
- 47 项测试通过，0.2.1 应用构建及签名校验通过。此次验证不调用云端模型。

## 已实现

- Bedrock Mantle Responses：`/openai/v1/responses`，通过 AWS SDK profile 凭证与 SigV4 签名调用。
- 默认两个阶段独立为 `GPT-6 Astra / medium / us-west-2`；配置在任务开始时固定，记录实际 model ID、路由、时间、响应 ID 和可用 token 用量。
- 长转录按片段分块校对，原始 ID 不改变；每个完成分块落盘，失败时保留原输入及部分结果。
- 修改必须逐字匹配输入片段、限于当前分块，拒绝修改人工保护区域。字词、数字、否定与条件等更改保留为待确认建议。
- 校对接受／撤销单独记录，纪要输入保存当时生效的文本。重新生成和人工纪要编辑不覆盖旧版本。
- 关键条目必须包含有效片段和逐字引用。负责人不能仅凭发言人身份推定；截止日期不接受没有逐字依据的推算。
- 校对与纪要 UI、错误及取消状态、版本选择、原文跳转、Markdown / TXT 导出。
- 退出或异常中断保留已有版本，允许手动重试；不无限自动重试请求，不自动降级模型或跨区域路由。

## 服务验证

用户授权用最新会议测试。开始工作时确定的记录约 8 分钟，176 段转录（应用轨 90 段，麦克风轨 86 段），无已标记缺口。

在提交这份会议前，先使用固定的无会议内容文字验证模型接口：

1. 修正独立使用 SDK 签名器时需要初始化 CRT 的问题。
2. 修正签名缺少 Host 的问题，并明确包含 payload SHA-256；离线签名测试覆盖 Host、会话 token、正文不变及签名头。
3. 服务端返回 HTTP 400，原因明确为：
   > Access to OpenAI models is not allowed from unsupported countries, regions, or territories.

这属于访问位置限制，不能通过目录可见、AWS 区域已支持或 STS 有效推断模型可调用。程序没有更换网络、端点、模型或区域来绕过此限制。最新会议未提交给 GPT 模型，也没有向其记录填入模拟生成结果。

## 自动化验证范围

`bash scripts/test.sh` 最终通过 **44 项测试，0 失败**。0.2.0 构建及本机签名校验通过。

除原有音频、转录、SQLite 和导出测试外，新增以下回归验证：

- 模型及推理配置校验、显式发送 medium、关闭 Responses 存储。
- 签名器独立初始化与完整请求签名。
- 校对人工保护、语义修改待确认、未知片段／越界分块拒绝。
- 原文引用存在性和逐字匹配、负责人及日期保守处理。
- 条件或建议不得自动变为确认决策。
- 不完整／拒绝输出不能成为成功纪要。
- 分块覆盖、失败保留、只重试未完成部分、纪要重试不重复校对。
- 校对选择使纪要过时、原始转录及旧输入快照保留、处理中断恢复。

测试使用合成样本，不将真实会议正文写入仓库。测试通过不代表已完成真实模型质量验收。
