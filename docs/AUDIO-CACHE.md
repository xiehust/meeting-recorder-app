# 本地录音缓存管理

设置中的“本地录音缓存”提供占用大小、会议数、音频文件数、可清理大小和使用中大小。打开设置时刷新，保持打开时每 15 秒更新，也可点击“刷新”。关闭新会议的默认缓存不会删除已有文件。

“一键清理…”在确认后清理未使用的录音缓存。自动清理提供永不、1 周、2 周、30 天、90 天；旧设置和新安装均默认永不自动清理。选择期限并保存设置后生效，适用于已有缓存。过期时间按会议结束时间计算；无对应已结束会议的孤立缓存按文件修改时间计算。应用启动时及运行期间每小时检查，关闭应用时不在后台执行，下次启动会补做检查。

正在录音、暂停、收尾、AI 处理或批量转录的会议，以及已保存为运行中状态的批量任务，均跳过清理。清理过程中不接受新录音或新的批量转录，避免文件读写冲突。退出应用会等待当前清理完成。

清理只处理应用资料目录 `Audio/<会议 UUID>/` 下的普通 CAF 文件，不跟随符号链接，不扫描备份或批量工作目录。扫描只读取文件元数据，不读取音频正文；占用大小按音频文件字节数统计。删除失败的文件保留并继续计入统计，同时在设置页显示错误。

清理不会删除会议、转录原文、人工修订、纪要、已有批量结果或云端文件。录音块的历史元数据保留。音频缺失或不完整时，录音复核页禁用新建复核并显示原因，已保存的文字结果仍可使用。

自动过期及手动清理的验证使用临时目录中的测试音频；验证过程不删除用户缓存。测试覆盖旧设置兼容、期限边界、正在使用的缓存保护、孤立缓存、符号链接隔离、部分删除失败及会议资料保留。
