# 识别语言 · 0.6.1

设置、开始记录和暂停后的语言菜单统一提供：

| 选项 | AWS 语言配置 | 匹配词汇表 |
| --- | --- | --- |
| 中文 | `zh-CN` | 中文 |
| English | `en-US` | 英文 |
| 日本語 | `ja-JP` | 日文 |
| 中英混合 | `zh-CN,en-US` | 中文、英文 |
| 英日混合 | `en-US,ja-JP` | 英文、日文 |

两种混合模式均使用 `IdentifyMultipleLanguages`。实时接口传入匹配的 `VocabularyNames`，批量接口通过 `LanguageIdSettings` 按语言匹配词汇表。未启用词条的语言仍可以正常识别；所选语言有启用词条时，要求对应词汇表已就绪。

英日模式不会使用中文词汇表，也不会要求中文词汇表 READY。中英模式同样不会使用日文词汇表。

界面语言、纪要输出语言和词条语言仍各自支持中、日、英，并独立于识别模式。

## 旧版本兼容

0.6.0 的 `multilingual` 三语配置保留解码和执行能力，供已有会议和已提交的批量任务使用。新录音的界面不再提供此选项；旧全局默认若为三语模式，启动后回退为原有的中英混合默认值。历史会议、转录、校对和纪要不会因此改写。

新英日模式的保存值为 `englishJapanese`，原有中英混合仍为 `mixed`。

## 验证

0.6.1 共 131 项测试通过（Core 54、Cloud 52、Audio 25），覆盖新选项、英日双路实时／批量参数、词汇表匹配、中文词汇表未就绪时的隔离及旧三语解码。使用独立的英日合成语音，通过原生 Swift SDK 实际完成英日实时与批量转录；批量任务及 S3 输入／输出已清理。没有发送用户会议内容，也没有更改用户词汇表或 AWS 权限。

打包后的应用已实际核对中文、英文界面下的菜单：中文、English、日本語、中英混合、英日混合，共五项。升级前后会议记录、原文校验表、AWS／录音配置、词汇表与模板库保持不变；界面恢复为跟随系统，音频缓存仍开启。
